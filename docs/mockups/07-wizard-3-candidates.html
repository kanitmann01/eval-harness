annotations 01-12

  1. 01
    step rail

    Third step current, earlier steps clickable. The rail count reads 6, the number of rows on this page, so the rail and the table agree.

  2. 02
    step title

    One line says what a row is. The matrix is the spec: changing a row here changes the YAML, so there is no separate review screen later.

  3. 03
    name

    Free text, unique per candidate, and the identity a compare view uses. Duplicating a name is an error under the name field, not a silent merge.

  4. 04
    prompt selector

    Options come from the prompt names set on step 1. A reference to a deleted prompt is an error under this field and names the missing prompt.

  5. 05
    context selector

    Defaults to the step 2 attachment, and a per row change here wins. Choosing none is valid and means prompt only.

  6. 06
    credential selector

    Lists credentials per adapter with their vault state. An untested credential is shown but not selectable, with the reason under the field.

  7. 07
    parameters

    Temperature and max_tokens are per row and copied from the model defaults. Editing here does not touch the other rows of the same model.

  8. 08
    add and remove

    Add candidate appends one row. Remove drops the row and its cells. The cell count and the rail estimate both update on the next paint.

  9. 09
    error summary

    A count at the top, the specific error under the field. Both, because a long matrix hides the field but never hides the count.

  10. 10
    blocked rows

    Blocked rows stay in the draft and stay counted separately. Next is still enabled, because step 4 shows exactly what a run would cost with them removed.

  11. 11
    keyboard

    The matrix is a table, tab order is row by row. A row can be removed with the keyboard, and focus lands on the next row's name field, not on the page top.

  12. 12
    mobile

    Each candidate becomes a card: name, model, prompt, context, credential, then the two numbers. Errors sit inside the card under the field they name.

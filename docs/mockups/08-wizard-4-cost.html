annotations 01-12

  1. 01
    step rail

    Last step current, every earlier step clickable. The rail estimate and the hero show the same number, both recomputed from one function.

  2. 02
    step title

    The step answers one question: what will this cost and what stops it. No settings live here, only the cap and the two exits.

  3. 03
    total

    One number, large, in the same place every time. The per model split sits beside it because one model at 3.00 and one at 0.25 is the story.

  4. 04
    cells and tokens

    Cells times tokens per cell is the whole estimate. Tokens per cell show prompt and completion separately, the ratio drives the price.

  5. 05
    medians source

    Says where the token numbers came from, how many cells, and which prices. An estimate with an unnamed source is a guess and would be labelled as one.

  6. 06
    cap and meter

    The cap is editable and comes from the spec. The meter is capped at 100 percent of the bar, the number beside it carries the truth, 170 percent.

  7. 07
    over cap

    Names the total, the cap and the percentage, then the three ways out. It is a warning, not an error, because Save only is still valid.

  8. 08
    create and run

    Disabled while the estimate exceeds the cap. The reason is the callout above it, not a tooltip, and the button stays visible so the exit is obvious.

  9. 09
    save only

    Enabled. Writes the YAML, leaves the comparison unrun, and lands on the edit page with a confirmation naming the file.

  10. 10
    nothing written

    Nothing exists on disk until one of the two buttons is pressed. Closing the tab loses the draft, as it should, the draft is not a file.

  11. 11
    write conflict

    If the file appeared between step 1 and here, the write is refused and names the path. Overwrite is a second, deliberate action.

  12. 12
    mobile

    The hero stacks: total, then the per model rows, then the cap and the meter. The two exits become a sticky bottom bar, Save only on the right.

annotations 01-12

  1. 01
    header

    The file name is the page title, the route says which file. Save and Save and run sit here, the rail's estimate sits with them, so cost is visible before you press either.

  2. 02
    identity line

    Modified time, last run and its gate verdict. Opening the editor to fix a failing gate starts by seeing which run failed and how.

  3. 03
    dirty state

    Set on the first edit and cleared on save. Leaving with unsaved changes asks once, the guard names how many fields changed.

  4. 04
    save and run

    Writes the file, then goes to the launch page with the spec pre-filled. Two steps, not one, because a run costs money.

  5. 05
    save disabled

    Disabled for one named reason: the file changed on disk at 19:41. The callout above states the reason and offers diff or reload.

  6. 06
    view YAML

    Quiet link to the raw editor at /specs/support-routing/edit. That page is not drawn in this set. The same validator runs on both sides, so a file saved here opens there without reformatting.

  7. 07
    sections

    The four wizard steps, collapsed into one page in the same order. Section anchors in the rail jump down, no accordions that hide the estimate.

  8. 08
    sticky rail

    The rail stays put while the body scrolls and shows the same numbers step 4 showed. A second estimate implementation would drift, so it is the same one.

  9. 09
    validation

    Errors appear under the field on save and on blur. Each one names field, value and fix, and the first invalid field gets focus.

  10. 10
    saved confirmation

    Inline under the last section, naming what changed. Not a toast, because a toast disappears before a screen reader reaches it.

  11. 11
    stale write

    If the file changes again between load and save, the write is refused, the diff opens, and nothing on disk is replaced.

  12. 12
    mobile

    One column. Save and Save and run move to a sticky bottom bar with the estimate in it, so the price and the button are always on screen.

annotations 01-12

  1. 01
    top strip

    Screen number, screen name and route. It belongs to the wireframe, not to the product: every mockup carries the same strip so a reviewer can name the page from a screenshot.

  2. 02
    top navigation

    Three items and one primary action. Runs carries the current mark. New comparison starts the wizard and is the only filled button on the page.

  3. 03
    page header

    Counts answer what has run, what needs attention, what is live. Attention means a failed gate, a partial run, an error or a cancellation, the same rule the runs query uses.

  4. 04
    compare selected

    Disabled at 0 of 3. It enables at 2 or 3 ticked rows and stays disabled at 1, because a comparison needs two sides. The hint under it states the rule instead of leaving the operator to guess.

  5. 05
    toolbar

    Filters are a GET with candidate, metric and status, so a filtered view is a linkable URL. When filtered the note becomes filtered view, N shown, and Clear appears.

  6. 06
    run table

    Column order follows the contract: spec and run id, graph, status, candidates, cells, pass rate, cost, duration, started. Row opens the run, not a modal.

  7. 07
    graph thumbnail

    The same spec graph at 96px, five fixed columns, no labels, so the shape still reads. Hidden below 768px; the mobile rows carry the numbers instead.

  8. 08
    status

    Run status and gate outcome are separate facts. Row 1 finished ok and failed its gate, so it shows both. The gate chip names itself on hover and in its accessible label.

  9. 09
    pass rate

    A fraction and a percentage, 10/12 is 83.3%, with a meter that repeats the number. The fraction stays visible because it is the evidence behind the percentage.

  10. 10
    cost

    Sum of cell cost. The toolbar note sums the view, so filters change the total. Cost is not an estimate here, it is recorded spend.

  11. 11
    running and error rows

    Running row: live dot, cells count up, cancel lives on the run page. Error row keeps its 3 recorded cells and says so, it does not read as zero.

  12. 12
    long list

    The table scrolls inside its own keyboard reachable region with a sticky header, so 200 runs do not push the toolbar away. Empty and filtered-empty are in 11.

what is not drawn, and why

6.7 YAML editor

/specs/{name}/edit keeps its old behaviour. 09 links to it as view YAML. Redrawing it would duplicate the validator surface twice.

6.8 launch

Step 4 in 08 carries the estimate, the cap and both exits. A launch page would repeat that and add a second place to change the cap.

tablet

823 wide is a layout change, not a screen. The 375 frames and the desktop frames cover the two ends.

loading

Skeletons need real row dimensions to be worth drawing. The design system forbids spinners, so nothing is drawn here.

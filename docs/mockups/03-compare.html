annotations 01-12

  1. 01
    header

    Route is /compare?runs=a,b, so a comparison is a link. It leaves the top nav unmarked on purpose: this view is entered from Runs or from a conversation, not from the nav.

  2. 02
    decision banner

    One glyph, one label, one sentence, then the deltas that drove it and the caveat. The recommendation is a claim about these two runs, not about the models.

  3. 03
    shared nodes

    A double frame marks any node both runs have: the 4 case ids and the 2 metric keys. Anything without the frame differs between the runs and is listed under the graphs.

  4. 04
    paired metric table

    One row per shared metric. A and B carry their own interval, the delta carries its own. Sorted by the size of the interval, not alphabetically.

  5. 05
    delta and interval

    Delta is B minus A with a paired interval. Crossing zero reads not separable with the reason under it, so nobody reports a win from noise at n=12.

  6. 06
    cost per correct

    Two numbers, one per run, cheapest first inside the cell. A run can win on quality and lose on cost, both are shown.

  7. 07
    judge column

    Names the judge that produced the metric and its config hash. Deterministic metrics say so. A judge change between runs would show here.

  8. 08
    one-sided cases

    Only cases where the runs disagree. Cases both runs pass are dropped, they carry no signal about the change.

  9. 09
    pick a winner then open cells

    The decision banner states the winner. The next action is opening the losing cell in its own run, so the recommendation is auditable in one click.

  10. 10
    guards

    Fewer than two runs, one run, no shared metric, different case sets. Each names the missing part rather than rendering a broken table.

  11. 11
    identical results

    When intervals overlap and the cells match, the page says no measurable difference. It does not pick a winner from a decimal.

  12. 12
    mobile

    Graphs stack, shared markers stay. The metric table becomes one card per metric: value, interval, delta, verdict.

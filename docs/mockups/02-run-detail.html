annotations 01-12

  1. 01
    crumbs and identity

    Route is /runs/2f9ac1d7. Crumb goes back to the list, the run id stays in mono next to seed and harness version so a report can be reproduced.

  2. 02
    verdict bar

    One row of six facts, in the same order as the template: status, pass rate, cost, cells, gates, duration. It is the whole answer before any scrolling.

  3. 03
    status and gate chip

    Two separate facts. The run finished ok and a gate failed, so both show. The chip carries an x glyph as well as the words, never tone alone.

  4. 04
    pass rate

    Percentage, fraction and the 95% Wilson interval. At n=12 the interval is wide, 65.0 to 85.5, and it is shown so a 83.3% is not read as a precise score.

  5. 05
    cost

    Spend against the cap with a meter. The cap comes from the spec snapshot, not from today's config, so re-running the same spec is comparable.

  6. 06
    duration and cancel

    Finished runs show duration only. While live, cancel renders in this slot, and it is the only destructive control on the page.

  7. 07
    spec graph

    Full width, five fixed columns: cases, prompts and contexts, candidates, metrics, gates and verdict. Same graph as the list thumbnail, larger and labelled.

  8. 08
    graph edges and state

    Hairlines, square corners. The failing edge is dashed with an x glyph and the failed gate is dashed too, so the failure survives a greyscale print.

  9. 09
    heatmap

    One row per candidate, one column per case, cell count on the right. Cell links are the only way into the sheet, so the sheet always has a cell in hand.

  10. 10
    cell sheet

    Opens for the selected cell: prompt, recorded answer, every check with reason and evidence JSON, telemetry, cost split, artifact links. Escape closes, focus returns to the cell.

  11. 11
    empty checks and error cells

    A cell with no checks says so instead of showing an empty table. An error cell shows the recorded error and its stack is not exposed, only the message.

  12. 12
    other states

    Running streams over SSE, cancelled names the partial count, budget exceeded names the cap, a missing artifact names the file. All four keep the rest of the page.

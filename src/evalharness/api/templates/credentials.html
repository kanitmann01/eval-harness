What the states mean

A state is read from stored metadata, never from the request. Only a verified or error credential is selectable in the spec editor, because both carry a successful test.

{{ status("verified") }}

A test passed; the editor may offer it.

{{ status("unverified") }}

Never tested; the editor refuses it until a test passes.

{{ status("disabled") }}

Switched off; the editor refuses it until it is enabled and tested again.

{{ status("error") }}

A test passed earlier and a later one failed; the last error is shown. The editor still offers it because a successful test exists.

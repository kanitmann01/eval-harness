What the states mean

  • verified A test passed; the editor may offer it.
  • unverified Never tested; the editor refuses it until a test passes.
  • disabled Switched off; the editor refuses it until it is enabled and tested again.
  • error A test passed earlier and a later one failed; the last error is shown. The editor still offers it because a successful test exists.

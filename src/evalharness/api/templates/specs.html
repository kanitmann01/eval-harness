Three ways to edit a spec

All three surfaces read and write the same YAML file; pick the one that fits the change.

New comparison wizard
Start a new comparison. Four steps write a new YAML file, and nothing touches disk until the last step.
Structured edit
Open a spec with Edit. A form for the common fields: cases, prompts, candidates, cost and rules. Save validates the whole file before writing it.
Raw YAML
Open a spec with YAML. The whole file, including fields the form does not show. Check validates without saving.

Compare does not edit a spec: it puts two run ids side by side, or two candidates from one run, and reports the delta with its 95% interval. Launch starts a run from a saved spec.

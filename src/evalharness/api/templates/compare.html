The rule

The point delta is B minus A. The dependent 95 percent interval uses each side's Wilson score bounds (Newcombe's hybrid score method), so it stays sensible at small n and at 0 or 100 percent. When the interval crosses zero the verdict is inconclusive, whatever the point delta says. A comparison across different judges is flagged and never called a win.

A side with no samples has no delta and no interval, so it is undefined rather than zero. Cost per correct answer divides the side's total cost by that metric's passed checks; it is undefined when nothing passed.

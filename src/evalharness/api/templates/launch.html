What happens next

  1. The spec is loaded, validated, planned and estimated exactly like a command line run. An invalid spec, an over-budget estimate or a busy console is refused here with the reason and nothing is recorded.
  2. The run executes in the background and writes its cells and events as they finish, so the heatmap and the live progress panel fill in without a reload.
  3. Cancel from the run page stops between cells: finished cells are kept, the remaining cells read cancelled, and the run is recorded as cancelled with its partial results.

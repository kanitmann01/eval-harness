Quick tour 1 / 5

Find your way around

  1. Runs is the home page. Every evaluation you execute lands here with its verdict, cost and gate result.

  2. Demos is the shortcut. Four scripted walkthroughs copy a real spec, run offline and open the trace, so you can see the engine before writing anything.

  3. Specs holds the YAML that declares cases, candidates, metrics and gates. Start here when you want to change what is evaluated.

  4. New comparison builds a new spec in four steps: what varies, the context, the candidates, then cost and rules. To put two finished runs side by side, use Compare in the navigation.

  5. Credentials stores provider keys encrypted. The bundled demos use a stub and need no key.
